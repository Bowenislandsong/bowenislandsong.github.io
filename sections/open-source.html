Editor extension

LaTeX One-Click

VS Code and Cursor-friendly LaTeX extension for local Tectonic builds, PDF preview, diagnostics, and SyncTeX source jumps.

Story
Writing LaTeX should not require a giant TeX install, a separate PDF workflow, and guesswork about source locations.
Aim
Give VS Code and Cursor users a local compile-preview loop that feels native.

The extension is published as LaTeX One-Click and keeps compilation local: it provisions Tectonic, resolves project roots, opens a PDF webview, and maps preview clicks back to source lines.

Research implementations and reusable code

Embodied ML

SER

SVD Embedding Regression code for estimating ground reaction forces from IMU signals with lightweight, inspectable models.

Story
The biomechanics work asks whether smaller low-rank models can beat heavier sequence models when deployment constraints matter.
Aim
Keep wearable force estimation accurate, interpretable, and realistic for edge use.

The repo is the code-facing companion to the wearable sensing work: low-rank embeddings, simpler regressors, and deployment-aware evaluation.

Reasoning + ranking

CoT-Rec

Chain-of-thought generation plus ranking, so candidate reasoning paths can be scored and selected instead of accepted in generation order.

Story
Reasoning traces should be treated like candidates: generate several, compare them, and choose deliberately.
Aim
Turn chain-of-thought sampling into a ranking problem with measurable selection behavior.

The project matches the ranking work elsewhere on the site: generate multiple candidates, evaluate them explicitly, and make selection measurable.

Large-file reconciliation

RCDS_GO

Go implementation of remote large-file reconciliation that syncs huge payloads by sending differences instead of whole files.

Story
Large files often differ in small ways, so sending entire payloads wastes bandwidth and time.
Aim
Make remote reconciliation scale with the difference between files, not just their total size.

This is the systems side of the RCDS paper: practical benchmarking, communication efficiency, and a concrete implementation.

Python package for payoff allocation in resource-sharing settings where fairness and incentives affect whether systems are adopted.

This package turns the allocation rule behind the cloud federation research into reusable code.

CI reliability

Flake Analyzer

Statistical tooling for classifying flaky tests and improving trust in CI results across distributed-system projects.

Story
A flaky test suite makes every real failure harder to trust and every release slower to ship.
Aim
Classify unreliable failures so teams can separate signal from noise in CI.

Flake analysis matters because noisy CI slows delivery, hides regressions, and makes teams less confident in their release signal.

Embodied ML

SER

SVD Embedding Regression code for estimating ground reaction forces from IMU signals with lightweight, inspectable models.

The repo is the code-facing companion to the wearable sensing work: low-rank embeddings, simpler regressors, and deployment-aware evaluation.

Reasoning + ranking

CoT-Rec

Chain-of-thought generation plus ranking, so candidate reasoning paths can be scored and selected instead of accepted in generation order.

The project matches the ranking work elsewhere on the site: generate multiple candidates, evaluate them explicitly, and make selection measurable.

Large-file reconciliation

RCDS_GO

Go implementation of remote large-file reconciliation that syncs huge payloads by sending differences instead of whole files.

This is the systems side of the RCDS paper: practical benchmarking, communication efficiency, and a concrete implementation.

Flake Analyzer

Statistical tooling for classifying flaky tests and improving trust in CI results across distributed-system projects.

Flake analysis matters because noisy CI slows delivery, hides regressions, and makes teams less confident in their release signal.

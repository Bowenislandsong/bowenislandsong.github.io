abstract: "Accurate estimation of ground reaction force (GRF) using wearable inertial measurement units (IMUs) is crucial for biomechanical analysis and rehabilitation. However, the inherent inter-subject variability poses a significant challenge. This paper introduces a novel deep transfer learning (DTL) framework with an adaptive hybrid loss function (AHLF) to address this challenge. The DTL framework leverages a pre-trained model on a large source dataset to extract generic gait features, which are then fine-tuned on a small target subject dataset for personalized GRF estimation. The AHLF adaptively balances the contributions of L1 and cosine losses based on the target subject's data characteristics, enhancing the model's robustness and personalization capability. Experimental results on a public dataset demonstrate that the proposed method outperforms existing state-of-the-art GRF estimation techniques, achieving superior accuracy and generalization performance. ## Summary
This paper presents a Deep Transfer Learning (DTL) framework combined with an Adaptive Hybrid Loss Function (AHLF) for personalized Ground Reaction Force (GRF) estimation using Inertial Measurement Units (IMUs). The method aims to address inter-subject variability by transferring knowledge from a pre-trained model on a large dataset to a target subject's smaller dataset.  The AHLF dynamically adjusts the weighting between L1 and cosine losses to optimize model performance based on individual subject characteristics.

## Key Contributions and Insights
*   A novel deep transfer learning (DTL) framework for personalized GRF estimation that leverages a pre-trained model on a large source dataset.
*   An adaptive hybrid loss function (AHLF) that dynamically balances L1 and cosine losses based on the target subject's data characteristics.
*   Demonstrated improved GRF estimation accuracy and generalization performance compared to state-of-the-art techniques on a public dataset.
*   Validation of the effectiveness of the DTL framework and the AHLF through ablation studies.

## Why this is State-of-the-Art
The approach utilizes transfer learning which reduces the need for large subject-specific datasets, addressing a significant limitation in personalized GRF estimation. The adaptive hybrid loss function is also novel, dynamically adjusting to individual subject data characteristics, thereby improving robustness and personalization capabilities.

## Weaknesses or Limitations and How to Improve
*   The study relies on a single public dataset, limiting the assessment of generalizability across diverse populations and gait patterns. Future work should evaluate the framework on multiple and more diverse datasets.
*   The complexity of the DTL framework and AHLF may increase computational demands. Further research should focus on optimizing the model architecture and loss function to improve computational efficiency for real-time applications.
*   The paper does not explore the impact of sensor placement or different IMU configurations on the performance of the proposed method. Investigating these factors could lead to more robust and practical GRF estimation systems.

abstract: "Ground reaction force (GRF) estimation plays a significant role in biomechanical analysis and human motion monitoring. Deep learning-based methods have demonstrated promising results in GRF estimation using inertial measurement units (IMUs). However, these methods typically rely on supervised learning, which requires substantial labeled data that are both expensive and time-consuming to acquire. This work proposes a novel self-supervised learning framework, Contrastive Masked Autoencoder (CMAE), to learn GRF-related representations from unlabeled IMU data, thereby reducing the reliance on labeled data. Specifically, CMAE incorporates a masking strategy that randomly masks parts of the input IMU data, and then reconstructs the original data, encouraging the model to learn robust and comprehensive representations. In addition, a contrastive learning module is introduced to pull representations of different views of the same sample closer while pushing away representations of different samples, further enhancing the discriminative power of the learned representations. The learned representations are then transferred to a GRF estimation task by fine-tuning a lightweight regression model using limited labeled data. Experimental results on a public dataset demonstrate that the proposed CMAE framework outperforms existing self-supervised and supervised methods, especially when labeled data is scarce, highlighting its potential for practical GRF estimation applications."

## Summary

The paper introduces a Contrastive Masked Autoencoder (CMAE), a self-supervised learning framework, to estimate Ground Reaction Force (GRF) from IMU data. This approach reduces the dependence on large amounts of labeled data by pre-training the model on unlabeled IMU data and then fine-tuning with a small labeled dataset. The framework uses a masking strategy and a contrastive learning module to learn robust and discriminative representations.

## Key Contributions and Insights

*   A self-supervised learning framework (CMAE) for GRF estimation using IMU data.
*   The CMAE incorporates a masking strategy to improve robustness.
*   A contrastive learning module is utilized to learn more discriminative features.
*   The framework achieves state-of-the-art performance with limited labeled data, outperforming existing supervised and self-supervised approaches.

## Why this is State-of-the-Art

This work is state-of-the-art because:

*   It addresses the challenge of limited labeled data in GRF estimation, a common bottleneck in deep learning applications in biomechanics.
*   It combines masking and contrastive learning, which are effective self-supervised techniques.
*   It demonstrates superior performance compared to other self-supervised and supervised methods when labeled data is scarce, a significant advantage for real-world applications.

## Weaknesses or Limitations and How to Improve

*   The framework is evaluated on a single public dataset. Evaluating on more diverse datasets would provide a more comprehensive assessment of its generalizability.
*   The selection of masking ratio and hyperparameters could be further optimized through a more systematic exploration.
*   The computational cost of the pre-training stage may be substantial. Investigating methods to reduce the computational burden, such as knowledge distillation or model compression, would enhance its practicality.
